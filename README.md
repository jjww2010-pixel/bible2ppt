# 사용자 제공 성경 본문 변환본

사용자가 업로드한 현대인의성경.txt와 쉬운성경.txt의 줄 순서에 권·장·절을 부여한 변환 파일입니다.
각 입력은 CP949 인코딩의 31,102줄입니다. 빈 줄도 절 위치로 유지해 66권·1,189장·31,102개 절 위치에 대응시켰습니다.
표준 장·절 배열, 66권의 시작 위치, 현대인의 성경 내 절 참조 표기, 요일 4:8과 마지막 절을 대조했습니다.
별도 공식 판본과 모든 문장의 정확성·완전성을 대조한 결과는 아닙니다.

파일 페이지에서 **Download raw file**을 눌러 받을 수도 있습니다.

## 적용 방법

JSON 사용을 권장합니다. JSON에는 원본 대조용 정보도 들어 있으며 선행·후행 공백을 포함한 본문을 보존합니다.

1. ZIP을 압축 해제합니다.
2. 최신 Bible2PPT에서 설정 화면의 **쉬운성경**을 선택하고 **성경 본문 가져오기**로 `Bibles/easy.json`을 가져옵니다.
3. **현대인의 성경**을 선택하고 `Bibles/modern.json`을 가져옵니다.
4. 제작 화면에서 사용할 번역을 선택합니다. 한 번역만 제작하려면 다른 번역을 제작 대상 목록에서 제거합니다.

또는 프로그램을 닫은 상태에서 ZIP의 `Bibles/easy.json`, `Bibles/modern.json`을 실행 파일 옆 `Bibles` 폴더에 복사할 수 있습니다.
기존 `krv.json`은 유지하세요. EXE를 새로 빌드할 필요는 없습니다.

`TXT` 폴더의 번호가 붙은 TXT도 가져올 수 있습니다. 이 형식은 가져오기 과정에서 본문 앞쪽의 공백이 정리될 수 있습니다.
`Audit` 폴더의 TSV는 원문 대조용이며 가져오기 파일이 아닙니다.

## 원본에서 확인한 사항

- 쉬운성경 원본의 7개 절 위치가 빈 줄입니다: **삿20:22–23, 삼하4:6–7, 왕상8:41–42, 렘16:2**.
  해당 위치에는 `[원본 본문 누락: 권장절]`을 넣었습니다. 이것은 성경 본문을 복원한 것이 아니라 누락 안내입니다.
- 현대인의 성경의 연속된 `N절과 같음` 729개를 통합 절 범위로 표시합니다. 예를 들어 6절과 7절이 같은 본문이면 `6–7절`로 한 번만 저장하고, 7절 요청도 같은 본문을 반환합니다.
- 연속되지 않은 참조 3개(레20:4 → 2절, 삼하3:36 → 34절, 대하9:16 → 14절)는 원본이 가리키는 본문에 연결했습니다.
- 현대인의 성경 **창22:23** 원문은 `(23절과 같음)`으로 자기 자신을 가리킵니다. 이 표기는 원문 그대로 남기고 오류 목록에 기록했습니다.
- 원문의 `(없음)` 표기, 소제목, 따옴표, 맞춤법·오탈자는 임의로 고치지 않았습니다.

## 검사와 원문 보존

`conversion-report.json`에 원본 SHA-256, 권별 시작 줄, 누락 위치와 참조 경고가 있습니다.
JSON의 `sourceLine`, `originalText`, `sourceMarkers` 정보를 이용해 **두 원본의 모든 줄을 정확히 재구성**하고 문자별 일치를 확인했습니다.
현대인의 성경은 30,373개 본문 항목이 31,102개 절 위치를 포함하며, 쉬운성경은 누락 안내 7개를 포함해 31,102개 항목입니다.

`Validation` 폴더에는 현재 프로그램의 C# 본문 조회 코드로 JSON·TXT 각각의 모든 절 요청을 검사한 결과가 있습니다.
이 검사는 파일 조회·선택과 숫자 대응을 확인하며, 원문의 번역 정확성이나 누락된 문장의 복원을 보장하지 않습니다.
실제 PowerPoint 슬라이드 렌더링은 이 검사에 포함하지 않습니다.

실제 Windows 검사 결과:

[Windows 실행 검사](https://github.com/jjww2010-pixel/bible2ppt/actions/runs/38288079356)에서 x64·x86 배포 EXE로 두 JSON·TXT의 모든 절 조회가 통과했습니다.
`Validation/Windows-x64`, `Validation/Windows-x86`에 각 파일의 SHA-256과 검사 결과가 있습니다.
배포 JSON·TXT는 Windows 검사 당시의 CRLF 줄바꿈으로 저장하여 검사한 파일과 SHA-256이 정확히 일치합니다. 본문 문자는 변하지 않았습니다.
